Architecture Spotlight

Caso de Éxito: Migración del Hub de Pagos a Digital Payments AKS (MetLife)

🚀 Liderazgo Técnico & Arquitectura de Sistemas

De Monolito Legacy Hub de Pagos Hexagonal a AKS Digital Payments

Lideré la concepción arquitectónica y ejecución técnica para migrar el sistema de pagos hacia una arquitectura de microservicios basada en Spring Boot 3 y arquitectura hexagonal (Ports & Adapters). Esto desacopló la lógica de negocio de los proveedores externos de pagos (TOKU, Transbank), garantizando tolerancia a fallos y alta escalabilidad transaccional.

La solución implementó Azure Kubernetes Service (AKS), Azure API Management para gobierno de endpoints seguros, y centralización de logs y métricas con Elasticsearch para trazabilidad end-to-end de cada transacción financiera.
